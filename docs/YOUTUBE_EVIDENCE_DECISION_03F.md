## Recommended route A contract for PM selection

1. **Text is authoritative for display.** Preserve the bounded provider `part.text` exactly through server snapshots, client retention and rendering. Do not replace it with parsed claims, strip model prose/URLs/IDs, or execute HTML/Markdown. Even a malformed legacy JSON answer remains fully visible as literal text; that is preservation, not a claim of clean prose. Never replay legacy malformed output as a newly verified natural summary.
2. Ask for concise attributed natural prose; optional conventional inline references such as `[segment-355]` use the supplied source IDs. Recognizing this exact marker is a best-effort annotation rule, **not** a guaranteed delimiter protocol. Missing/malformed markers never gate display. Preserve them as plain text; only code-created annotations become links. No raw model URL becomes a trusted citation.
3. Resolve only exact current-snapshot IDs, never offsets, neighboring IDs, model timestamps or fuzzy text matches. Display the **whole original caption segment** when it fits the existing240-character excerpt limit. This supplies quote membership by construction and removes multilingual quote-copying errors. For a longer segment, retain the answer and mark that reference unconfirmed with the full source preview available; do not pretend a clipped excerpt supports the whole claim. All428target segments fit (maximum82characters), which does not prove arbitrary-source coverage.
4. Use response/part-level source references, with markers kept at their original positions. Do not invent claim boundaries or label every statement supported because one reference matches. Keep at most8reference groups/3IDs per group, existing transcript16000-character and registry snapshot/backlog bounds. An over-limit attachment produces a notice without truncating answer text below the existing transcript bound. Duplicate IDs may be deduplicated for display; unknown IDs remain unconfirmed, without replacement. Exact excerpt/startSeconds/URL come from stored sections/videoId;355must yield1040.594seconds, never the model's value.
5. Separate attachment states (pending / source matched / unconfirmed / incomplete) from generation state and semantic acceptance. Label source-matched references as excerpts found in this source, with support still to be checked. If any reference is unresolved or none exists, explicitly show **“Source references unconfirmed. Check the source preview.”** Even all matched IDs do not auto-certify the answer.
6. Finalize attachments only for the matching source/run/turn/item/response on successful terminal output; treat in-flight references as pending. Stop freezes received answer text, pending references become incomplete, and no late callback can promote them. Keep the registry's final Stop snapshot before source disposal. Source removal/replacement/expiry closes the session and prevents reference reuse. No new source lookup/ownership rule, transport, timer or model call.

**Limits that remain:** the captured354reference would now resolve a real but **wrong** caption rather than be rejected for quote mismatch. This is openly weaker evidence of claim support, so a matched label must say only source membership. The semantic test must fail that answer. A canonical excerpt also does not validate arbitrary quotation marks/quoted words in the natural answer; review those against the source. PM selection includes replacing per-claim serialization with response/part annotations while retaining per-claim semantic acceptance. Optional references are not permission to accept zero references, conceal failure or call03F complete. If canonical segment evidence proves too coarse in evaluation, return to PM; do not add retrieval, quote-repair or another verification generation.
