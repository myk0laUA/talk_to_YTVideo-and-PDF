Source read/delete policy: foreign, missing, expired, nonready, synthetic-proof, unsupported-kind and stale replaced/deleted records are uniformly unavailable (404); corrupt genuine stored JSON is a generic storage failure (503). ## Exact distinctions and limitations

- Anonymous authority is possession of a valid signed bearer cookie, not a verified human identity. A genuinely stolen valid B cookie grants B's visitor authority; supplying a B ID, arbitrary owner field, or invalid cookie does not. HMAC randomness/signature, host-prefix/HttpOnly/Secure/Strict flags and duplicate-cookie rejection are tested; cookie loss creates a new visitor and does not recover old content.
- Genuine uploaded PDF/YouTube records occupy one active owner slot. Public caption cache/coordinator holds validated public transcript data keyed by video/language/native mode, with no visitor ID, credential or private PDF content. Cache hits still commit distinct visitor-owned Sources and require ordinary authorization. Cache internals are not exposed as a route. Source removal does not delete shared public cache. Existing cache/coalescing/fallback units run in the full unit suite; dedicated cache HTTP suites are retained from earlier tasks because cache code/policy did not change.
- Synthetic proof is an independent deterministic record with exact authored content/provenance/owner/expiry, not any READY database row. The proof store projection does not inspect `kind`; exact synthetic identity/content/provider is its capability predicate. Real uploaded rows cannot satisfy that predicate. Only diagnostic routes issue credentials. There is still no production uploaded-source voice/text factory or credential issuance integration, and actual model accounting remains unsupported/fail-closed.
- Proof attempts use fixed-window process-local counters, not a distributed spend limit. Proof: visitor6/network20/global20/lifetime100/concurrent2. Issuance: visitor3/network10/global20/lifetime50/concurrent2. PDF:6/20/20/40/concurrent1; captions:4/8/8/16 with one extraction slot, up to eight compatible import participants. All clients share `unverified-network`; forwarded IP/host fields are ignored. Restarts/multiple processes reset or multiply counters, visitor rotation bypasses only per-visitor counts, and proxy/hosted enforcement is NOT_RUN.
- Failed/invalid admitted requests consume attempts; finally releases active occupancy only. Real mint has one eight-second timeout/no retry; request cancellation withholds output after pending work returns but does not abort the in-flight mint or instantly release its lease. A noncooperating store promise may retain a lease until it settles. Tests release held operations deliberately and prove no late authority/active lease leak afterward, not a universal bound on arbitrary injected database work.
- Post-mint validation rechecks the fetched proof snapshot's expiry/ownership and visitor expiry/cancellation, not a fresh SQL row. TTL does not revoke an already issued/connected session. A short-lived client secret can be reused and session settings changed by its holder; origin checks, counters, safety IDs and TTL do not bind it irrevocably to a source or provide a hard spending cap. No actual provider behavior is established here.
- Real SQL constraints/races/cleanup, proxy behavior, actual provider rejection/issuance, token accounting, live grounding, deployment, physical phone/audio and actual persisted BFCache remain **NOT_RUN** for 11C. Earlier PM evidence retains its original identities. No human key/phone/purchase action is needed to review this task.
