## Native transport and source-before-audio barrier

The adapter creates one native peer, an ordered reliable `oai-events` channel and one owned non-autoplay audio element. It negotiates `addTransceiver("audio", {direction:"sendrecv"})` without getUserMedia or a sender track. Initial text-only output, null input transcription/VAD, every complete ordered source-item ACK, final effective voice settings and settled writes all pass through the accepted PrimingController. Only its final barrier calls getUserMedia. Returned tracks are immediately disabled; async `replaceTrack` must settle before the lifecycle enables input. Permission denial is terminal and leaves Text mode as an explicit user choice.

Native message parsing accepts bounded whole UTF-8 JSON events (24,576 bytes/event, 32,768 events and 16 MB received per connection), without an incoming backlog. Ordered outgoing writes have a bounded FIFO (4,104 entries, 8,065,536 queued bytes), a 65,536-byte channel high-water mark, 32,768-byte low-water notification and one fixed 5-second drain deadline. Each send checks the negotiated SCTP message size against the 16,384-byte application maximum; an undersized transport fails rather than changing the server manifest. Malformed/oversized events, errors/close/disconnect and unconfirmed ACKs fail closed. Existing response/transcript bounds still apply independently.

The lifecycle retains its bounded preparation/connection/priming/media/interruption waits; native connection acquisition additionally has a 15-second deadline. HTTP readers bound size, MIME and body lifetime through abort, cancel stalled/late bodies, and consume late rejections. Source expiry owns one connection timer. Stop/replacement/removal/mode change/departure/expiry invalidate the attempt first, remove subscriptions/timers, close channel/peer once, pause/clear audio and stop each owned track once. A late getUserMedia result is disabled/stopped without attachment; no stopped async result can enter a replacement. Credential expiry bounds negotiation, not the active session; source expiry ends this local connection.

Official OpenAI documentation searched/opened 20 October 2026: [Realtime WebRTC](https://developers.openai.com/api/docs/guides/voice-webrtc). The implementation uses its ephemeral-key SDP `/v1/realtime/calls` contract. It does not use GPT-Live/unified examples or change the accepted 07G model/settings. The source-before-microphone ordering is an application integration decision verified offline here, not a live compatibility claim. Next 16.4.2's bundled Route Handler guide was consulted; the cancellation Node route is dynamic with explicit no-store/nosniff method denials.
